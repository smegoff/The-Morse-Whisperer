# CW Trainer

The trainer generates local CW audio and plays it through `audio_output_device`.

Known-good output:

```text
plughw:2,0
```

Use the web UI:

1. Open **CW Generator / Trainer**.
2. Enter text such as `VVV THE MORSE WHISPERER TEST 73`.
3. Choose pitch and WPM.
4. Press **Play CW**.

The trainer is useful for testing the decoder without needing a radio signal.
